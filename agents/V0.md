# Milestone V0: Static Pages at app.stellahu.me

## Goal
Five empty, mobile-friendly screens live at `https://app.stellahu.me` with HTTPS. No backend, database, auth, or feature integrations.

## Scope
- React + Vite PWA shell (already scaffolded: Home, Notes, Schedule, Countdowns, Settings).
- Basic bottom navigation between screens.
- Responsive layout, safe-area insets, works at 375px viewport.
- Build: `pnpm build:web` produces `dist/web/`.

## Out of scope for V0
- Any backend (Hono, Node, SQLite, D1, Workers).
- Auth, login, sessions.
- `/api/health` or any API endpoint.
- Google OAuth, Calendar, Gmail.
- OpenRouter / LLM calls.
- Background jobs, cron, backups.
- VM, Docker, Caddy, GCP, Tailscale, SSH.
- Porkbun Static Hosting, Netlify, Vercel, Firebase, S3/CloudFront.

## Deployment target (V0)
**Cloudflare Pages via GitHub Actions Direct Upload.**
- Project created in Cloudflare dashboard (Direct Upload, not Git integration).
- `wrangler pages deploy dist/web --project-name=<project>` runs in a GitHub Actions workflow.
- Workflow triggered manually (`workflow_dispatch`) on `main` branch; other branches are skipped.
- Deploy calls the reusable CI workflow for the same commit (web typecheck, lint, tests, build). The deploy job requires that build to succeed and uploads its `web-build` artifact without rebuilding. Failed, cancelled, or skipped builds cannot deploy.
- Production environment `production` with required reviewer (owner approval on phone).
- Secrets: `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID` stored in GitHub Actions secrets.
- Custom domain `app.stellahu.me` attached in Pages project settings.
- DNS: **CNAME record at Porkbun** (`app` → `<project>.pages.dev`), assuming Porkbun manages DNS for `stellahu.me`. Cloudflare issues TLS automatically.

## Non-goals (explicit)
- Do not add backend code, Dockerfile, docker-compose.yml, Caddyfile for V0.
- Do not provision GCP VM, static IP, firewall, Tailscale.
- Do not create database, migrations, auth, or API routes.
- Do not use Cloudflare's Git integration; Actions owns the deploy.
- Do not move DNS off Porkbun; CNAME is sufficient for subdomain.

## Rollback
If deploy fails: previous `*.pages.dev` URL remains active. Re-deploy previous commit SHA via Actions. No database or state to restore.
